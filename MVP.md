# Mega Image Editor — стартовый MVP

Это короткий рабочий план. Большая спецификация остаётся справочником, но разработку начинаем только с описанного здесь.

## Цель

Собрать минимальное Windows-приложение, в котором пользователь создаёт проект, импортирует картинку, видит её на холсте, сохраняет проект в собственный формат и снова его открывает.

Это ещё не полноценный редактор и не готовый AI-продукт. Это фундамент первого AI-сценария.

## Один пользовательский сценарий

1. Запустить приложение.
2. Нажать **New Project**.
3. Импортировать PNG.
4. Увидеть картинку на холсте.
5. Сохранить проект в нашем формате на базе `mega-file`.
6. Закрыть и повторно открыть проект.
7. Убедиться, что картинка и структура проекта восстановились.
8. Экспортировать результат в новый PNG.

Исходный PNG никогда не перезаписывается.

## Интерфейс

На первом этапе достаточно одного окна:

```text
┌──────────────────────────────────────────────┐
│ New  Open Project  Save Project  Import  Export │
├──────────────────────────────┬───────────────┤
│                              │ Project       │
│           Canvas             │ - Assets      │
│                              │ - Layers      │
└──────────────────────────────┴───────────────┘
```

UI делаем на `mega-ui`. Холст отображаем через `wgpu`.

## Данные проекта

Внутри `mega-file` пока храним только:

```text
/manifest.bin
/assets/{id}/image.png
/documents/main.bin
/previews/thumbnail.png   # можно добавить позже
```

Манифест содержит только версию формата, тип документа и идентификатор импортированного ресурса.

## Что реализуем

- Windows-приложение на Rust;
- создание пустого проекта;
- импорт одного PNG;
- один документ и один растровый слой;
- отображение изображения;
- pan и zoom холста;
- сохранение и открытие проекта через `mega-file`;
- экспорт в новый PNG;
- сообщения об ошибках открытия и сохранения.

## Что пока не реализуем

- кисть и ластик;
- несколько слоёв;
- undo/redo;
- выделение и трансформации;
- JPEG и WebP;
- анимацию и комиксы;
- AI-провайдеры и генерацию;
- тайлы и оптимизацию больших изображений;
- плагины, настройки и сложный docking.

## Порядок работы

1. Поднять окно с `winit`, `wgpu` и `mega-ui`.
2. Показать пустой viewport.
3. Импортировать и показать PNG.
4. Описать минимальную модель проекта.
5. Сохранить её через `mega-file`.
6. Открыть сохранённый проект.
7. Добавить экспорт PNG.
8. Проверить полный сценарий вручную и тестами формата.

## Готово, когда

MVP завершён, если сохранённый проект можно закрыть и открыть без потери импортированного изображения, а экспорт создаёт корректный PNG, не изменяя исходный файл.

После этого выбираем **одну** первую AI-функцию и делаем следующий короткий MVP вокруг неё.
